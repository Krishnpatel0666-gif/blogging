# LaptopVerse 💻

LaptopVerse is a frontend blogging and laptop discovery website created for a Web Application Development academic project.

## Technologies
- HTML5
- CSS3
- JavaScript
- LocalStorage
- Responsive design

## Main Features
- Responsive home page
- Laptop collection with search
- Brand/category filters
- Price/name sorting
- Laptop detail pages
- Wishlist using LocalStorage
- JavaScript login/signup validation
- Demo account stored in browser
- Dark/light theme
- Wallpaper generator/download
- Blog articles
- Mobile responsive navigation
- GitHub Pages ready
- No database required

## Run locally
1. Download or clone the repository.
2. Open the folder in VS Code.
3. Open `index.html` in a browser.
4. For the best development experience, use VS Code Live Server.

## GitHub Pages
1. Create a GitHub repository, for example `LaptopVerse`.
2. Upload all project files while keeping the folder structure.
3. Go to Settings → Pages.
4. Select the main branch and `/ (root)`.
5. Save and open the generated GitHub Pages URL.

## Viva points to explain
### HTML
Used for semantic structure, navigation, forms, cards, articles and page content.

### CSS
Used for responsive layouts, cards, buttons, themes, animations, spacing and mobile design.

### JavaScript
Used for:
- Search and filtering
- Sorting
- Dynamic laptop cards
- Wishlist
- LocalStorage
- Login/signup form validation
- Password show/hide
- Theme switching
- Wallpaper generation

### Why no database?
The project requirement says database connectivity is not required. LocalStorage provides a simple browser-based way to demonstrate wishlist and demo account functionality.

## Important note
Laptop prices/specifications in this educational demo are sample data and should not be treated as live retail pricing.
